# Educational Network Security Tools

This directory contains educational tools and examples for learning about network security concepts.

## Contents

- `network_monitor.py` - Basic network traffic monitoring example
- `stress_test.py` - Authorized network stress testing tool
- `defense_examples/` - Examples of defense mechanisms

## Usage Guidelines

All tools in this directory are for educational purposes only and should only be used on systems you own or have explicit permission to test.

## Learning Objectives

1. Understand network traffic patterns
2. Learn about system resource monitoring
3. Explore defense mechanisms
4. Practice ethical security testing
